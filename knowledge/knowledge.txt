
Python 基础知识

Python 是一种高级编程语言，具有语法简洁、易于学习、生态丰富等特点。Python 常用于 Web 开发、数据分析、人工智能和自动化脚本开发。
Python 使用变量保存数据。变量不需要提前声明类型，Python 会根据赋值内容确定变量的类型。例如，name = "张三" 创建一个字符串变量，age = 18 创建一个整数变量。
Python 使用函数组织可重复执行的代码。通过 def 关键字可以定义函数，函数可以接收参数，也可以使用 return 返回结果。

FastAPI 基础知识

FastAPI 是一个基于 Python 的 Web 框架，常用于开发 Web API。它支持根据类型注解校验请求数据，并能自动生成交互式 API 文档。
FastAPI 通常使用路由函数处理 HTTP 请求。例如，使用 @app.get("/items") 可以定义一个处理 GET 请求的接口。

RAG 基础知识

RAG 的英文全称是 Retrieval-Augmented Generation，中文通常称为检索增强生成。它结合信息检索与大语言模型生成，让模型在回答问题之前，先从外部知识库中查找相关内容。
一个基础 RAG 系统通常包括文档加载、文本切分、文本向量化、向量检索、相关性筛选和答案生成等步骤。
Embedding 是将文本转换为数值向量的技术。语义相近的文本，其向量通常也具有较高的语义相似度。
余弦相似度是一种衡量两个向量方向相似程度的方法。在向量检索中，可以使用余弦相似度对候选文本进行排序，优先选取与用户问题更相关的文本。

MySQL 基础知识

MySQL 是一种关系型数据库管理系统，可以使用表存储结构化数据。表由行和列组成，每一行通常代表一条记录，每一列代表一种数据字段。
SQL 是用于操作关系型数据库的语言。常见操作包括使用 SELECT 查询数据、使用 INSERT 插入数据、使用 UPDATE 修改数据，以及使用 DELETE 删除数据。
